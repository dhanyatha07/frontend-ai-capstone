## Coding Conventions

- Write clean and readable code.
- Use meaningful variable and function names.
- Keep functions small and focused.
- Follow Conventional Commits.
- Add comments only when they improve clarity.

## Git Commit Style

Examples:

docs: update README

feat: add new feature

fix: fix a bug

chore: update configuration

## Project Rules

1. Validate all user-entered settings before saving them. Display names must not be empty or whitespace-only, and emails must use valid email formatting.

2. Handle localStorage data defensively. Missing, malformed, or incorrectly typed stored values must fall back to safe defaults instead of crashing the application.

3. Every user-facing form must provide accessible feedback using semantic HTML, associated labels, keyboard-accessible controls, and an aria-live status region for success and error messages.

4. AI-generated code must be manually verified before being considered complete. Test the important user flows and do not rely only on the AI assistant's reported test results.
